**Status:** LOCKED — flat capsule look (James, 2026-09-23)  
**Against:** Proto greybox combat board

## Tone

Board-game tokens on cream paper. Soft pastel capsules. Thick outline. Almost zero interior detail. Board and VFX clarity beats illustration.

## Detail budget (do not reopen without asking James)

- Body = one soft capsule / cloud-pill  
- Face = two black dots (smile optional)  
- Family ID = one tiny mark (leaf / flame / cloud bump)  
- Tier = capsule size + one silhouette add only  
- No fur, shading texture, gradients, or illustrated anatomy
